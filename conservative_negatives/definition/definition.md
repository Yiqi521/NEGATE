# Over-conservatism 的可操作定义（Step 1，实现版 v1，2026-09-14）

记场景 s 的专家未来轨迹为 τ*（8 个位姿，0.5 s 间隔，后轴系），候选轨迹 τ 与 τ* **共路径、仅纵向剖面不同**（由生成算子保证）。
τ 为**保守负样本**当且仅当 C1 ∧ C2 ∧ C3 ∧ C4：

| 判据 | 实现（`scripts/build_negatives.py` + `filters/pdm_eval.py`） | 默认阈值 | 校准状态 |
|---|---|---|---|
| C1 安全通过 | 官方 PDMSimulator（LQR + 自行车模型，4 s @ 10 Hz）回放 τ，PDMScorer 计算 NC、DAC、TTC | NC = DAC = TTC = 1（DDC 记录不门控，v1 权重为 0） | 固定 |
| C2 进度显著更低 | EP(τ) / EP(τ*) | **≤ 0.8**（v1 校准后；原 0.7） | 已校准，见下表 |
| C3 无正当谨慎理由（事后验证） | 参考轨迹 τ_ref：专家行驶中 → 速度 ×1.15；专家 t0 静止 → **提前 1.0 s 起步**（v2 修正）。τ* 与 τ_ref 在同一日志未来中均满足 C1 → 更果断也安全 → 谨慎不必要 | 两者 NC = DAC = TTC = 1 | v1（仅 ×1.15）：转向 60.5%、汇入 96.6%、直行穿越 99.5%（静止起步时 ×1.15 无判别力，故 v2 改为提前起步） |
| C4 近专家 / 非平凡 | 路径一致（构造保证）且 EP 比 ≥ 0.3（排除“几乎不动”的平凡负样本） | ≥ 0.3 | 计划原用 ADE ≤ 2 m；实测纵向差异型负样本 ADE 中位数 ≈ 2.0 m，故改用 EP 比 |

## 前置过滤
- 运动学：速度 ≥ 0，加速度 ∈ [−4.0, 2.5] m/s²（试跑通过率 77%）。
- 算子适用规则：G1（延迟起步）、G4（过大间隙）仅在专家 t0 静止（< 0.5 m/s）时生成。

## 辅助字段
- `conflict_clear_s`：未来 8 帧中最后一次有运动车辆进入自车 20 m 范围的时刻，供 G4 使用。
- `expert_conservative`（计划中的专家保守性标记）：**尚未实现**，需 PDM-Closed 参考进度；metric cache 中 `metric_cache.trajectory` 即 PDM-Closed 轨迹，可直接比较进度，列入下一步。

## 已知偏差与待办
1. G3（提前制动）在默认网格下几乎不产生负样本：要么运动学不可行，要么进度差不足。待办：改为“在专家不停车的场景中制动到停止”并放宽 brake_dist。
2. C3 只用日志回放（非反应式），他车不会对更快的自车做出反应；这是 NAVSIM 层面的固有限制，写入论文局限。
3. 遮挡几何代理特征尚未实现（计划 C3 的辅助字段）。

## C2 / C4 阈值校准（navtest interact 两类 891 场景，2026-09-14）
数据：`results/c2_c4_calibration_navtest.csv`（仅统计通过运动学、C1、C3 的候选）。

| C2 ≤ | C4 ≥ | 负样本 | 覆盖场景 | 转向场景 | 汇入场景 | G1 / G2 / G3 / G4 | EP 比中位 |
|---|---|---|---|---|---|---|---|
| 0.70 | 0.3 | 562 | 477 | 413 | 64 | 67 / 477 / 0 / 18 | 0.63 |
| 0.75 | 0.3 | 733 | 501 | 431 | 70 | 74 / 641 / 0 / 18 | 0.64 |

| 0.85 | 0.3 | 1224 | 525 | 448 | 77 | 98 / 1025 / 72 / 29 | 0.73 |

**决定**：v1 采用 C2 ≤ 0.8、C4 ≥ 0.3。理由：0.8 能纳入速度缩放 0.65 的候选（EP 比约 0.77），使每个场景平均约 2 条负样本；0.85 开始纳入 EP 比 > 0.8 的“几乎不慢”样本，风险 R2（太容易）上升。

**未达标项**：计划要求 G1–G4 各占 ≥ 15%，实际 G2 占 90%。原因：(a) 无保护转向场景中专家 t0 静止的只有 32 / 802，G1、G4 按适用规则很少触发；(b) G3 在 C2 ≤ 0.8 下为 0。待办：G3 改为“专家不停车场景中制动至停止”并放宽制动距离；对 G2 增加非均匀速度剖面（先慢后追）以降低同质性。此项在 P2 阶段末复评。

**其它观测**
- 事后验证 C3 场景级通过率：无保护转向 60.5%、汇入 96.6%。即约四成转向场景中“更快的专家”在回放中不安全，谨慎有正当理由——过滤器按预期工作。
- 专家保守性标记（EP 相对 PDM-Closed < 0.7）：159 / 891 = 17.8%，接近 R11 的 20% 触发线，评估时须分层报告。
- 专家在回放中全部通过 NC / DAC / TTC（0 例失败）。

### 诊断与修复（v2 → v3）
- **Bug**：`operators.py` 的弧长重采样把目标弧长截断在专家路径终点，且速度剖面漏掉原点→首位姿段。后果：C3 的“更果断”参考轨迹进度反而低于专家（如 11.2 m → 10.0 m），事后验证对静止起步场景失去判别力（通过率 99.5%）。
- **修复**：弧长与速度剖面从原点起算；超出专家终点时沿末端航向线性外推。自洽性测试：恒等速度剖面复原误差 0.0 m。
- 修复后 12 个直行穿越样本中，提前 1 s / 2 s 起步的参考 EP 升至 0.67–1.00 且全部 NC = TTC = DAC = 1，即这些场景里更早起步在日志回放中确实安全。
- v3 用修复后的算子重跑，结果见下。

### 发现：非反应式回放对“正当谨慎”的判别力有限（v3）
- C3 场景级通过率 97.8%，只有 19 / 802 个转向场景的参考轨迹在回放中触发 TTC / NC。原因与计划第 3 章预见一致：日志中的他车已经对真实自车（更谨慎）做出过反应，所以“更果断的自车”在回放里很少撞上任何人。
- 后果：当前负样本标签主要由 C1 / C2 / C4 决定，C3 几乎不起作用；若直接用于训练，风险 R1（把有理由的谨慎误标为过度保守）不可忽视。
- 对策（v4 起）：新增**间隙代理** `ref_min_gap_s`：对 t0 时 30 m 内的运动车辆做恒速外推，找到与参考轨迹路径最近的交汇点，计算自车到达时刻与他车到达时刻之差的最小绝对值。若 `ref_min_gap_s < gap_thresh`（默认 2.0 s），视为存在实质冲突、谨慎有理由，C3 不通过。该判据在论文中作为“反应式验证不可得时的保守替代”。
- 仍需人工审查子集验证 C3 + 间隙代理的标签质量（计划 κ ≥ 0.6）。
